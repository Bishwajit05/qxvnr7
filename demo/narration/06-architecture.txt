The architecture separates source retrieval, analysis, and presentation. A Python provider requests the two permitted Elexon datasets and normalizes their records. FastAPI performs publication selection and accuracy calculations. React and TypeScript display the results and the source status. The dashboard endpoint returns the selected decision, January analysis, metadata, and freshness from one dataset epoch, preventing panels from mixing independently refreshed versions. Docker builds the frontend and packages it with the Python application. Vercel serves the frontend and runs the same ASGI application as a Python function. A bundled snapshot is retained only for an explicitly identified upstream failure, rather than as the application's ordinary data source.
