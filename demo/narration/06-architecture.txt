For the technical review, the architecture has four responsibilities. An offline Python importer retrieves the two permitted Elexon datasets. A read only SQLite snapshot stores forecast revisions and normalized actuals. FastAPI performs the as of selection and all accuracy calculations. A React and TypeScript frontend renders the controls, charts, evidence, and data coverage. The frontend does not independently recalculate the statistics. Docker builds the React assets and packages them with the Python application and snapshot. Keeping this historical data in the release makes the demonstration reproducible and independent of an external API call on every page load. It also avoids introducing a separate database service for a fixed one month pilot.
