The repository includes React, Python, the API provider, analysis tests, Docker setup, and deployment configuration. The README documents the directory structure, run commands, source rules, cache behaviour, failure handling, and AI assistance. The unified dashboard response keeps every view on one dataset epoch, while CSV export makes selected evidence inspectable. Manual refresh retrieves the historical records again; it does not turn this January pilot into a current trading dashboard. Cache memory is disposable and local to a server instance, a deliberate simplification for this bounded demonstration. Before handoff, verify the public application without a login, inspect the refresh status, and watch the regenerated local video. The video remains local at the candidate's request, and no submission form is sent automatically.
