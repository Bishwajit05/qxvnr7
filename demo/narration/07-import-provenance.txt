The provider fetches the fixed historical source windows from Elexon, preserving target times and publication times. It caches a successful normalized dataset in process memory for three hundred seconds. Each Vercel instance owns its own cache, so a cold instance performs its own request. The manual refresh endpoint bypasses that interval. Successful retrieval records the source URLs, attempt time, and retrieval time. A failed refresh retains the last good dataset, its original successful retrieval time, and an explicit stale error status. If no successful API data exists, an upstream failure can use the bundled snapshot with its original metadata and a fallback label. It must never masquerade as a fresh API result.
