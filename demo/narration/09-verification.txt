The tests cover the behaviours that would undermine the analysis if they were wrong. Domain checks exclude future publications, include an exact cutoff, retain valid zeroes, require complete actual hours, and verify the error formulas. A partial coverage regression prevents different samples from reversing the apparent revision result. Provider tests exercise real request construction, cache reuse, forced refresh, and failure handling without depending on an external service during the test run. Frontend interactions check that actuals and accuracy are immediately available and that refresh state is visible. The continuous integration workflow runs Python tests, frontend interaction tests, TypeScript checks, and the production build. The final source and production checks must also confirm that the deployed app reaches the real Elexon endpoints.
